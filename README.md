# ipl-match-analysis-powerbi
Interactive IPL Match Analysis Dashboard (2008–2025) built using Microsoft Power BI, featuring season-wise KPIs, winners and IPL Match Analysis Dashboard (2008–2025) | Power BI
Project Overview -

This project presents an interactive IPL (Indian Premier League) Match Analysis Dashboard built using Microsoft Power BI, covering seasons from 2008 to 2025.

The dashboard provides insights into match statistics, team performance, player achievements, season winners, and tournament standings through interactive visualizations and season slicers.

Tools Used -
Microsoft Power BI
DAX (Data Analysis Expressions)
Data Visualization
KPI Cards
Interactive Slicers
Points Table Analysis

The dashboard includes KPI cards to analyze:

Total Matches
Total Sixes
Total Fours
Total Teams
Total Venues
Total Centuries
Total Half-Centuries

Dashboard Features -

1. Season-Wise Analysis

An interactive season slicer allows users to select a season from 2008 to 2025 and explore the corresponding tournament statistics.

2. Season Winner and Runner-Up

Displays the season winner and runner-up based on the selected IPL season.

3. Top Sixes Analysis

Highlights teams and players with the highest sixes counts.

4. Top Fours Analysis

Shows teams and players with the highest fours counts.

5. Orange Cap Analysis

Displays player and team details along with the relevant performance count for Orange Cap analysis.

6. Purple Cap Analysis

Displays player and team details along with the relevant performance count for Purple Cap analysis.

7. Points Table

Presents the IPL standings to help compare team performance in the selected season.

Interactive Features :

Season slicer covering 2008–2025
Dynamic winner and runner-up selection
Season-based filtering of dashboard visuals
Interactive KPI cards and performance comparisons
Project Objective

To analyze IPL match and player performance data across multiple seasons, identify team and player achievements, and present cricket statistics through an interactive Power BI dashboard.
